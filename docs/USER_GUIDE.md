# Guia do usuário

## Primeiro uso

1. Instale OBS Studio, abra-o e ative o WebSocket Server com senha.
2. Crie uma coleção de cenas chamada `VALE STREAM STUDIO` ou use nomes prefixados com `VALE_`; não substitua cenas existentes.
3. Crie fontes de câmera, microfone, áudio de desktop e captura de tela/janela no OBS. O app consulta as fontes e tipos que o OBS realmente expõe.
4. No app, conecte em Configurações e confirme o indicador verde de OBS.

## Aula e apresentação

Abra o arquivo em Apresentações. Para PPT/PPTX, instale LibreOffice se solicitado. Use a janela de apresentação para capture no OBS e avance as páginas. Para compartilhar com convidados, crie uma sala e use o botão de compartilhamento que abre o fluxo de tela/áudio do VDO.Ninja no navegador. Confirme a recepção do áudio no dispositivo do convidado; o toggle do navegador não prova entrega.

## Reunião

Crie uma sala nova a cada reunião. Copie apenas o convite de convidado. Abra o link de anfitrião para usar chat e controles que o VDO.Ninja fornecer. O serviço externo pode falhar em redes restritivas; nesse caso gravação e RTMP local continuam disponíveis.

## Gravação e live

Configure o formato e pasta de gravação no OBS; MKV é preferível para maior tolerância a interrupção. O botão Gravar chama o OBS e mostra o estado retornado. Para live, configure URL/chave oficial de um destino por vez. Depois de iniciar a saída do OBS, talvez seja necessário acionar publicação no painel do YouTube/Facebook. Nunca grave participantes sem aviso e consentimento.
