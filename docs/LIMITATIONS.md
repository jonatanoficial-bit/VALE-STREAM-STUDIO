# Limitações honestas da Parte 1

- Não existe servidor VALE, autenticação de convidados, TURN, SFU ou garantia de funcionamento universal de reuniões.
- VDO.Ninja, conta de live, internet e hardware são dependências externas. A disponibilidade não é contratual pelo app.
- O preview principal do OBS não é embutido nesta etapa; o usuário verifica a janela do OBS. O app não simula pixels de preview.
- A criação de fonte usa os tipos disponibilizados pela instalação OBS. Propriedades específicas de câmera/monitor podem variar por versão; ajuste-as no OBS e confirme a fonte no programa.
- Áudio do sistema para convidados depende do fluxo e permissões do navegador/VDO.Ninja; deve ser testado no dispositivo remoto.
- PPT/PPTX pode perder animações, vídeos e fontes especiais na conversão para PDF.
- Parte 1 configura apenas uma live de saída por vez. Multistream YouTube + Facebook simultâneo é trabalho futuro, sujeito a pipeline local testado.
- Testes de câmera, microfone, tela, gravação, conta de live e múltiplas redes não foram executados neste ambiente sem hardware/contas reais.
