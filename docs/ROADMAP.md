# Roadmap

## Parte 1 - base operacional

Interface Electron, ponte OBS local, gravação, uma live RTMP por vez, PDF/PPTX local e convite VDO.Ninja. Este é o escopo do código atual; a validação física segue a matriz de testes.

## Parte 2 - multistream e produção

Pipeline local sustentável para YouTube + Facebook simultâneos, com isolamento de falhas, medição real de upload, layouts e mixagem refinada. Não será anunciado antes de teste real de queda de destino.

## Parte 3 - aula e distribuição

Landing estática de convite no GitHub Pages, acessibilidade/atalhos, pré-entrada aprimorada, QR e distribuição de instalador por Releases. GitHub Pages continuará sendo apenas HTML estático, nunca servidor de mídia.
